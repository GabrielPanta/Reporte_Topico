Guía de Uso del Consolidador de Personal

Esta herramienta procesa y concatena automáticamente los datos de trabajadores desde SQL Server o Excel generando exactamente los 23 campos solicitados:

Estructura de las 23 Columnas del Consolidado:

  1. Regimen
  2. Tiene Digitacion (jornal)
  3. RutTrabajador
  4. CodigoTrabajador
  5. Apellidos y Nombres
  6. FechaNacimiento
  7. Sexo
  8. Edad
  9. FechaInicioPeriodo
  10. FechaInicioContrato
  11. FechaTerminoContrato
  12. Oficio
  13. Zona Labores
  14. SubCentroCosto / Cuartel
  15. ACTIVIDAD
  16. LABOR
  17. ENCARGADO
  18. PLACA
  19. CODIGO BUS
  20. RUTA
  21. TURNO
  22. HASTA
  23. ESTADO

Lógica de Evaluación de Estado:

  • ESTADO = "ACTIVO": Si el Rut/DNI registra marcación en Archivo 3 o digitación = NO.
  • ESTADO = "AUSENTE": Si NO registra marcación y no tiene una inasistencia justificada.
  • ESTADO = [Valor de ACTIVIDAD]: Si registra una inasistencia (ej. "LICENCIA POR MATERNIDAD", "DESCANSO MÉDICO", "VACACIONES", "PERSONAL CON S.P.L", etc.).
Conexión Segura: La conexión a SQL Server se realiza localmente desde el servidor Python hacia vfstbd01.
